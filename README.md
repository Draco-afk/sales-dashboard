# แดชบอร์ดยอดขาย สิงหาคม 2569

แดชบอร์ดยอดขายของร้านกาแฟและเบเกอรี 3 สาขา (มหาวิทยาลัย, สำนักงาน, ห้างสรรพสินค้า) จากชีต Sales ในไฟล์ `1Amazon_Quick_Workshop test.xlsx` จำนวน 100 รายการ

> **ข้อมูลจำลองเพื่อการเรียนรู้**

## หน้าเล่าเป็นเรื่อง 6 ตอน ตามลำดับการนำเสนอ

- **เปิดเรื่อง**: รายได้รวม จำนวนที่ขายรวม กำไรขั้นต้นรวม และทุก ฿100 ที่ลูกค้าจ่ายแบ่งเป็นต้นทุนกับกำไรเท่าไร
- **1 เงินมาจากไหน**: ตารางเปรียบเทียบรายได้ของแต่ละสาขา และรายได้ตามหมวดหมู่
- **2 อะไรขายดี**: กราฟแท่งสินค้าที่มีรายได้รวมสูงสุด 3 อันดับ
- **3 ขายดี แล้วกำไรดีด้วยไหม**: อันดับตามรายได้เทียบกับอันดับตามกำไร และกำไรต่อหน่วยของแต่ละเมนู
- **4 ขายดีวันไหน**: ปฏิทินรายได้รายวัน ใบสรุปการขายของวันที่เลือก และค่าเฉลี่ยตามวันในสัปดาห์
- **5 เจาะดูเอง**: ตัวกรอง 5 แบบ จัดกลุ่มได้ 6 มุม ดูตัวเลขได้ 6 ชนิด กดช่องเพื่อดูรายการขายจริง เรียงลำดับ และค้นหา
- **6 สรุป**: ข้อสรุป 3 ข้อ วิธีคำนวณ และที่มาของข้อมูล

เลือกสาขาที่มุมขวาบนเพื่อให้ทั้งหน้าเล่าเรื่องของสาขานั้น กดลูกศรขวา/ซ้ายเพื่อเลื่อนไปตอนถัดไป/ก่อนหน้า หรือกดเลข 1–6 เพื่อข้ามไปตอนนั้น

## วิธีเปิด

`dashboard.html` เป็นไฟล์เดียว เปิดในเบราว์เซอร์ได้เลยโดยไม่ต้องติดตั้งโปรแกรมหรือต่ออินเทอร์เน็ต (ฟอนต์ฝังไว้ในไฟล์)

## วิธีคำนวณ

- รายได้ = จำนวนขาย × ราคาขายต่อหน่วย
- กำไรขั้นต้น = จำนวนขาย × (ราคาขายต่อหน่วย − ต้นทุนต่อหน่วย)
- อัตรากำไรขั้นต้น = กำไรขั้นต้น ÷ รายได้
