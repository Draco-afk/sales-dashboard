# แดชบอร์ดยอดขาย สิงหาคม 2569

แดชบอร์ดยอดขายของร้าน 3 สาขา (มหาวิทยาลัย, สำนักงาน, ห้างสรรพสินค้า) จากชีต Sales ในไฟล์ `1Amazon_Quick_Workshop test.xlsx` จำนวน 100 รายการ

> **ข้อมูลจำลองเพื่อการเรียนรู้**

## มีอะไรบ้าง

- **แท็บสำหรับผู้บริหาร**: รายได้ กำไรขั้นต้น จำนวนที่ขาย สามเรื่องที่ควรรู้ สัดส่วนแต่ละหมวดหมู่ สินค้าที่ทำรายได้สูงสุด ตารางเทียบสาขา ตารางสินค้า × สาขา และรายได้รายวัน กรองตามสาขาและหมวดหมู่ได้
- **แท็บสำหรับพนักงานร้าน**: เลือกสาขาของตัวเอง ดูเมนูขายดีเป็นแก้ว/ชิ้น ปฏิทินยอดขาย และกำไรต่อแก้ว

## วิธีเปิด

`dashboard.html` เป็นไฟล์เดียว เปิดในเบราว์เซอร์ได้เลยโดยไม่ต้องติดตั้งโปรแกรมหรือต่ออินเทอร์เน็ต (ฟอนต์ฝังไว้ในไฟล์)

## วิธีคำนวณ

- รายได้ = จำนวนขาย × ราคาขายต่อหน่วย
- กำไรขั้นต้น = จำนวนขาย × (ราคาขายต่อหน่วย − ต้นทุนต่อหน่วย)
- อัตรากำไรขั้นต้น = กำไรขั้นต้น ÷ รายได้
